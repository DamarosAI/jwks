What a node is

A node is the site's own Damaros instance: evidence, signatures, and the execution record stay under site governance. PHI does not leave; only network-safe signal goes out. Every join raises the value of the nodes already live, without anyone surrendering control of the endpoint. Node one is valuable alone.
