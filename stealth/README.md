# Stealth

One flag puts the whole site behind a single screen: the Damaros mark and name on a contour survey,
cancer-care markers falling in trails, and the pointer as a probe that ablates them. No product
language anywhere a person, a crawler or a model can read it.

    VITE_STEALTH=1 npm run build

With the flag set, the build:

- serves `stealth/index.html` as `index.html`. Every route already rewrites to it, so `/about` and
  `/privacy` show the same page;
- overwrites `llms.txt`, `sitemap.xml` and `site.webmanifest` in `dist/` with the copies in this folder.

Without the flag nothing changes: `src/`, `public/` and the root `index.html` are untouched, and the
full site builds exactly as before. To go dark, set `VITE_STEALTH=1` in the Vercel project's
environment variables and redeploy. To come back, remove it and redeploy.
`VITE_STEALTH=1 npm run dev` previews it locally.

## What is in the page

`stealth/index.html` is one dependency-free document: no React, no bundle.

- **The survey.** `topo-page.svg`, inlined. Generated by `make-topo.py`: the summit sits under the
  mark with its innermost ring left open, every fifth line is an index contour in the house blue, and
  the rest alternate slate and blue.
- **The trails.** `damarosTrails()` in the inline script draws them on a canvas. Six trails share one
  speed at fixed phases, so four or five are always readable at different heights. Each wraps into a
  fresh column, never one through the name, its neighbours', or the pointer's. Markers are tumor and
  cancer-care markers only, set in IBM Plex Mono, which loads from Google Fonts.
- **The probe.** In range, a marker locks: it deepens and trembles. Touched, it is ablated. Kills
  inside 0.7s chain, and a tally appears top-right from the first kill. Idle blips invite the first
  move and retire after three kills. Reduced motion freezes the trails and the mark.
- **The mark.** The outline drum, moving only in the plane of the screen: a slow float and the site's
  axis shimmy.

## Regenerating

    python3 stealth/make-topo.py            # needs numpy; writes topo-page.svg and topo-banner.svg
    node scripts/make-stealth-banner.mjs    # renders assets/damaros-linkedin-banner-stealth.png

After regenerating `topo-page.svg`, paste it over the `<svg class="topo">` element in `index.html`.
